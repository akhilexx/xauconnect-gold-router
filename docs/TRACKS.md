# Track fit (ids from nearhackathon.com/HACKATHON.md)

- `defi` (Unstoppable DeFi): cross-chain trading that settles through NEAR Intents, no custodian.
- `realworld` (Real-World Money): stablecoins -> tokenized gold savings rail; "something a normal company could use tomorrow" (treasury diversification into gold).
- `agents` (Agent Economy): HTTP API + policy engine so an agent can move value across chains via NEAR Intents within hard limits.
- Optional: `security` if the policy engine is extended (function-call keys, per-agent budgets).
